# Starline v3 — «Проблема рынка»

## Цель

Добавить самостоятельный блок `#market-problem` сразу после `#industries`. Он должен объяснять разрыв между оптимизированным CPA и фактическим ростом GMV, чтобы следующий блок «Когортный подход» воспринимался как ответ на эту проблему.

## Новая последовательность смысла

`Hero → Задачи → Услуги → Индустрии → Проблема рынка → Когортный подход → Результат подхода → Процесс → Palitra → Кейсы → Заявка`.

Для этого checkpoint меняются только новый блок и его позиция: `Cohorts` переносится после `market-problem`; `Economics` сохраняет `id="economics"` и позднее будет оформлен как «Результат подхода».

## Reference lock

Основной источник — предоставленный пользователем скриншот v2. Сохраняются: светлый фон, крайне крупный полупрозрачный индекс, асимметрия «сообщение слева / доказательства справа» и тонкие разделители. Из существующего v3 сохраняются Onest/Inter, фиолетовый `#3F09B1` только для смысловых акцентов, ночной текст `#171027`, открытые поля и отсутствие декоративных карточек.

Выбран вариант A «Номер как масштаб». Он не копирует v2: индекс меняется на `07`, текст и сигнальные строки получают отдельный компонентный контракт, а фон остаётся спокойным без отдельной иллюстрации или анимации.

## Контент и структура

`MarketProblem.astro` — единственный источник разметки:

- eyebrow: `Проблема рынка`;
- H2: `Реклама может выглядеть эффективной, пока бизнес почти не растёт`;
- пояснение о том, что оптимизация CPA и атрибуции не гарантирует GMV, а маркетинг нужно связывать с новыми клиентами и будущей выручкой когорт;
- декоративный, скрытый от assistive technology индекс `07`;
- две статичные сигнальные строки: `CPA` и `GMV` с утверждёнными пояснениями из v2;
- никаких кнопок, JavaScript, auto-play, marquee или неподтверждённых claims.

`/preview/market-problem/` импортирует только `MarketProblem` в `BaseLayout`; header, footer и соседние секции в него не входят.

## Адаптивность и доступность

На desktop — двухколоночная композиция: крупное сообщение и пояснение слева, CPA/GMV rail справа. Прозрачный индекс не участвует в чтении. На tablet композиция сохраняет две области с уменьшенным индексом. На `640px` rail становится обычной вертикальной последовательностью под текстом; индекс не должен перекрывать контент или вызывать горизонтальный overflow. Контент доступен без JavaScript и без motion.

## Проверка

До реализации расширить структурный тест: порядок section IDs, импорт нового компонента, `market-problem` между Industries и Cohorts, наличие isolated preview, точный headline/сигнальные строки и отсутствие motion-dependent markup. Production HTML test должен ожидать `#market-problem` и две signal lines. После реализации: `npm test`, `npm run check`, `npm run build`, `npm run test:build`, затем preview и полный лендинг на 1440×900, tablet и 390×844.

## Решения

| Решение | Основание | Причина |
|---|---|---|
| Светлая асимметричная секция | v2 reference | Создаёт паузу после тёмных Industries и подводит к Cohorts. |
| Ghost-index `07` | user brief + v2 reference | Даёт запоминаемую структуру без новой иллюстрации. |
| Только тонкие разделители | v3 contract + Refero anti-slop | Сигналы CPA и GMV — содержание, не набор карточек. |
| Purple только для CPA/GMV и eyebrow | v3 tokens | Поддерживает смысловую иерархию, а не превращает фон в декоративный акцент. |
