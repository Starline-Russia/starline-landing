# Starline v3: аккуратные пересечения орбит Palitra

## Цель

Убрать визуально случайный узел в местах пересечения двух орбит секции Palitra, не меняя её композицию, контент и метафору системы.

## Согласованное решение

Использовать вариант A — чистый переход сверху:

- горизонтальная орбита воспринимается как передняя;
- вертикальная орбита прерывается коротким зазором в каждой точке пересечения;
- поверх зазора проходит тонкая горизонтальная линия;
- ширина зазора остаётся минимальной: он должен разделять глубину, а не превращаться в декоративный эффект;
- цвет, прозрачность и толщина видимых линий сохраняют текущий сдержанный характер.

Не добавлять световые точки, анимацию, новые подписи или дополнительные орбиты.

## Реализация

Заменить два декоративных `div`-эллипса внутри `Palitra.astro` одним скрытым от accessibility tree inline-SVG. В SVG:

1. Нарисовать вертикальный эллипс через маску.
2. Использовать более широкий штрих горизонтального эллипса внутри маски, чтобы вырезать четыре коротких прозрачных разрыва из вертикальной линии.
3. Поверх вертикального эллипса нарисовать обычный тонкий горизонтальный эллипс.

Прозрачные разрывы покажут реальный градиент секции, поэтому в точках пересечения не появится несовпадающая цветовая подложка. Центральный знак Palitra останется отдельным HTML-элементом поверх SVG.

Размеры эллипсов задаются в общей SVG-системе координат и адаптируются на мобильном брейкпоинте без JavaScript. Видимая толщина линий должна оставаться близкой к текущему `1px`.

## Границы изменения

- Не менять заголовок, описание и четыре области Palitra.
- Не менять центральный знак и строку senior-контроля.
- Не менять фон секции и соседние секции.
- Не добавлять motion или интерактивность.

## Preview и проверка

Добавить `/preview/palitra/`, который рендерит единственный общий компонент `Palitra` внутри `BaseLayout`.

Структурный тест должен подтвердить:

- наличие изолированного preview;
- использование общего `Palitra.astro`;
- наличие декоративного SVG и SVG-маски;
- отсутствие дублированной разметки секции в preview.

После реализации выполнить:

- `npm test`;
- `npm run check`;
- `npm run build`;
- `npm run test:build`;
- визуальную проверку `/preview/palitra/` и полной страницы на `1440×900`, `390×844` и tablet;
- проверку отсутствия горизонтального overflow, console errors и зависимости от JavaScript.
