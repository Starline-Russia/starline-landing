# Starline v3: удаление орбит Palitra

## Цель

Убрать визуально случайные пересечения декоративных линий из секции Palitra и упростить центральную композицию.

## Согласованное решение

Удалить горизонтальную и вертикальную орбиты полностью. Не заменять их другими линиями, световыми точками или анимацией.

## Реализация

Удалить `.palitra-orbit`, `.orbit-horizontal` и `.orbit-vertical` из компонента и CSS, включая мобильный брейкпоинт. Центральный логотип Palitra остаётся отдельным HTML-элементом.

## Границы изменения

- Использовать copy, утверждённый в browser annotations от 17 июля 2026 года.
- Заменить числовые индексы областей на булеты с официальным знаком Starline.
- Не менять центральный знак и строку senior-контроля.
- Не менять фон секции и соседние секции.
- Не добавлять motion или интерактивность.

## Preview и проверка

Добавить `/preview/palitra/`, который рендерит единственный общий компонент `Palitra` внутри `BaseLayout`.

Структурный тест должен подтвердить:

- наличие изолированного preview;
- использование общего `Palitra.astro`;
- отсутствие orbit-разметки и orbit-стилей;
- наличие четырёх Starline-булетов;
- отсутствие дублированной разметки секции в preview.

После реализации выполнить:

- `npm test`;
- `npm run check`;
- `npm run build`;
- `npm run test:build`;
- визуальную проверку `/preview/palitra/` и полной страницы на `1440×900`, `390×844` и tablet;
- проверку отсутствия горизонтального overflow, console errors и зависимости от JavaScript.
