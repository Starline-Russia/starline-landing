# Starline v3: интерфейс чата Palitra

## Цель

Добавить после текущей фиолетовой секции Palitra отдельный светлый блок, который показывает управление маркетингом через привычный чат AI-агента.

## Контент и композиция

- Фон секции — белый.
- Единственный заголовок: `Управление в привычном чате AI-агента`.
- Заголовок расположен сверху по центру.
- Под заголовком по центру расположен оригинальный скриншот `chat.jpg` из Google Drive: `Старлайн / Diz / palitra`.
- Скриншот не обрезается и сохраняет исходное соотношение сторон `1280 × 916`.
- На широком экране изображение ограничено шириной около `1180px`; на мобильном занимает всю доступную ширину.
- Изображение отделено от белого фона тонкой светлой рамкой, лёгкой тенью и небольшим радиусом скругления.
- В секции нет дополнительного текста, кнопок, декоративной графики или анимации.

## Архитектура

- Создать общий компонент `src/components/PalitraChat.astro`.
- Скопировать исходный скриншот в `src/assets/palitra/chat.jpg`, чтобы Astro оптимизировал изображение и сохранил intrinsic-размеры.
- Добавить новую секцию `palitra-chat` на главную страницу сразу после `palitra` и перед `cases`.
- Добавить изолированное превью `/preview/palitra-chat/`, которое импортирует только общий компонент внутри `BaseLayout`.
- Стили секции разместить в `src/styles/global.css` и не дублировать в превью.

## Адаптивность и доступность

- Использовать содержательный русский `alt`, описывающий интерфейс чата Palitra.
- Указать intrinsic-размеры через Astro Image, чтобы исключить скачок макета.
- На ширине `390px` заголовок остаётся читаемым, изображение не вызывает горизонтальный overflow и не обрезается.
- На desktop, tablet и mobile между заголовком и скриншотом сохраняется ясная визуальная иерархия.
- Секция полностью читаема без JavaScript и не требует интерактивного поведения.

## Тестирование

- Сначала обновить source contract: новый компонент, точный заголовок, локальный chat-asset, единственный компонент в preview и порядок `palitra → palitra-chat → cases`.
- Запустить структурный тест и подтвердить, что он падает из-за отсутствующего компонента и секции.
- После реализации выполнить `npm test`, `npm run check`, `npm run build` и `npm run test:build`.
- Визуально проверить `/preview/palitra-chat/` и полную страницу при `1440 × 900`, tablet width и `390 × 844`, включая отсутствие горизонтального overflow и ошибок в консоли.

## Вне рамок задачи

- Не изменять текущую фиолетовую секцию Palitra.
- Не редактировать содержимое исходного скриншота.
- Не добавлять карусель, lightbox, подписи или интерактивность.
